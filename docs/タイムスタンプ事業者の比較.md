# 総務大臣認定タイムスタンプ事業者の比較

作成: 2026-10-31

> **この文書の位置づけ**
> 総務省・各社のサイトは、この調査環境から直接取得できませんでした。**検索で得られた公開情報（報道資料の要約、各社の発表、解説記事）に基づく**ため、
> **料金・API・契約条件は、各社への問い合わせで確認するまで確定情報として扱わないでください。**
> 「確認」は、複数の情報で裏づけられたこと、「要確認」は、情報がない・古い・二次情報のものです。

## 2. 本システムに必要な条件（事業者に確認する項目）

本システムは、Supabase の Edge Function から、**HTTPS で RFC 3161 の要求を送る**方式です（`supabase/functions/timestamp/`）。次の条件を満たす事業者でないと、そのままでは使えません。

| # | 確認すること | 理由 |
|---|---|---|
| 1 | **RFC 3161 の HTTPS エンドポイント**があるか（要求は `application/timestamp-query`、SHA-256 に対応） | 現在の実装はこの方式。独自APIの場合は通信部分の差替えが必要 |
| 2 | **認証方式**（Basic、Bearer、**クライアント証明書**、IP制限、APIキーなど） | 現在の実装は、`Authorization` ヘッダーに載せる方式のみ。クライアント証明書やIP制限は、Edge Function から使えない可能性がある |
| 3 | **料金体系**（初期費用、月額、1スタンプの単価、最低利用、未使用分の扱い、有効期間） | 想定量（月100〜数百件程度）で、最低月額が割高にならないか |
| 4 | **保存期間を通じた検証**（法令の要件①）と、**期間を指定した一括検証**（要件②）の方法 | 認定の要件。再検証スクリプトに使うCA証明書の入手方法も含む |
| 5 | **有効期間と延長**: 法人は7年、欠損金の事業年度は10年の保存。トークンの有効期間（概ね10〜11年とされるものがある）と、延長（アーカイブタイムスタンプ）の手段 | 10年保存の書類で、期限切れにならないか |
| 6 | **可用性・上限**: 同時リクエスト数、レート制限、障害時の保証、サービス停止時の連絡 | 付与が遅れると、期限（7営業日・2か月+7営業日）に響く |
| 7 | **契約主体**: 直接契約できるか（小規模事業者でも可か）、代理店経由のみか | 手続・費用 |
| 8 | **認定の維持**: 名称変更（DiaStamp など）後の認定の扱い、認定の有効期限 | 認定が外れると、付与済みのタイムスタンプの扱いが変わりうる |

## 3. 暫定の見方（推測を含む。各社の回答で確定する）

- **RFC 3161 での連携が明確なのは、アマノ（サービス名に3161、開発ライブラリ提供）**。ただし接続仕様と料金は未確認。
- **料金が公開されている形跡があるのは、GMOグローバルサイン**。ただし最低月額（10,000円〜）が、少量の利用では割高になる可能性がある（約2年前の情報）。
- **単価が安いとされるのは、ウイングアーク1st**。ただしAPI・契約条件が不明で、新しい認定（令和7年8月）。
- セイコーソリューションズは、Java API・コマンド中心に見える。HTTP（RFC 3161）での直接利用は要確認。
- 三菱電機デジタルイノベーション、サイエンスパークは、情報が少ない。
- **まず問い合わせる候補（推測）**: アマノ、GMOグローバルサイン、ウイングアーク1st。ほかの3社も、同じ質問票（§2）で並行して問い合わせてよい。

## 4. タイムスタンプが要る場面と、要らない進め方（国税庁の資料で確認済み）

詳細は `docs/電帳法対応方針.md` §4。**費用を抑えたい場合の選択肢**として:

| 対象 | タイムスタンプが必要か |
|---|---|
| スキャナ保存（紙を読み取って紙を廃棄する） | **実質必要**（自社システムの保存日時では代えられない。スキャナ保存 問32） |
| 電子取引（受領・送付したPDF等） | **次のいずれか**: タイムスタンプ／**訂正削除の防止に関する事務処理規程**（問30）。本システムは授受をしないので、「訂正削除不可のシステム」は使えない（問37） |
| 自社作成書類の控え（紙で渡す分） | 不要（電子データの保存要件のみ） |

- **タイムスタンプを使わない進め方**: 電子取引は事務処理規程で対応し、紙の書類は紙のまま保存（スキャナ保存をしない）。この場合、事業者の契約は不要。
- **タイムスタンプで厳格に進める**（現在の方針）: 受領書類・送付PDFの登録のたびに付与。月の件数 × 単価 + 最低月額が費用になる。
- 想定件数（月の受領書類・送付PDFの数）が決まると、費用の見通しを出せる。

## 5. 次にやること

1. 想定件数（月の受領書類・送付PDF）を決める。
2. 候補2〜3社に、§2の質問票で問い合わせ、見積と接続仕様書を取り寄せる。
3. 選定後、`TSA_URL`・`TSA_NAME`・`TSA_AUTH` を Supabase の secret に設定し、`timestamp` 関数を実際のTSAでテストする（通信部分の差替えが必要な場合は、仕様書を元に対応）。
4. 認定事業者のCA証明書を入手し、`scripts/verify_timestamp.sh` で再検証できることを確認する。
5. 総務省の最新の一覧と、選定した事業者の認定の有効性を、契約前に確認する。

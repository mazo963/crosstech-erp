# 操作マニュアル（CROSSTECH 販売管理システム）

作成: 2026-11-01（画面の実装に合わせて作成。画面や機能を変えたら、同じ変更で更新する）
備付け書類の区分: 電子帳簿保存法施行規則第2条第2項第1号ハ（入出力要領などの具体的な操作方法）
関連: 手続・担当・期限は `docs/事務手続書.md`、システムの構成は `docs/システム概要書.md`

## 0. 基本

- **ログイン**: メールアドレスとパスワードで入ります（Supabase Auth）。ログインしても、スタッフとして登録されていなければ、業務データは見られません（管理者に登録を依頼）。
- **権限**: 管理者＝すべて（設定・税率・口座の変更を含む）／事務＝日常の登録・発行・取消／閲覧のみ＝見るだけ（ボタンが出ません）。
- **画面の構成**: 左のメニュー（ダッシュボード／売上＝見積・案件・納品・請求・入金／書類＝帳票・受領書類・出力／マスタ・設定＝得意先・外注先・税率・設定）。案件の画面は、左に入力、右に**発行イメージ**（A4）が出ます。
- **金額はシステムが計算します。** 画面で電卓計算した値を入れません。数量・単価・税区分を入れると、行金額（円未満切捨て）と消費税（請求書1枚・税率ごとに1回の端数処理）が決まります。
- **削除はありません。** 間違えたときは「取消」（理由が必須）をして、入れ直します。取消した行も記録として残ります。

## 1. 最初に1回だけ（管理者）

| 設定 | 場所 | 内容 |
|---|---|---|
| 自社情報 | 設定 | 会社名、適格請求書発行事業者の登録番号（T＋13桁）、住所、電話、FAX、メール、担当者名、見積書の有効期限の日数 |
| ロゴ・社印 | 設定 | PNG／JPEG（約280KBまで）。帳票に載せる画像。登録しただけでは、発行済みの帳票は変わりません |
| 振込先の口座 | 設定 → 振込先の口座 | 複数登録できます。請求書に載せる「既定」の口座を1つ選びます。使わなくなった口座は無効にします（削除はしません） |
| 請求書を正式にする | 設定 | オンにすると、このシステムの請求書が正式な請求書（適格請求書）になります。オフのときは「ERP控え・社内用」と表示されます |
| メール・Box | 設定 | Box（メール取込）のアドレス、メール署名 |
| タイムスタンプ | 設定 | このシステムで付与するかどうか。外部（Box など）に任せるときはオフ |
| スタッフ | 設定 | 名前・権限・有効。新しいスタッフの追加は、Supabase の管理画面（Authentication）でユーザーを作り、`staff` に登録します（README） |
| 税区分と税率 | 税率 | 標準税率・軽減税率など。税率は適用開始日つきで登録し、**さかのぼって変更できません**（管理者のみ） |

## 2. マスタの登録

- **得意先**（得意先メニュー）: 会社名、フリガナ、担当者名、**担当部署名**、郵便番号、住所、電話、適格請求書番号、**締め日**、**支払月・支払日**、請求の基準（納品ごと／全納完了時）、メール（請求書用・納品書用の TO／CC）、**納入場所（既定）**、帳票への**住所・担当部署・担当者の表示（既定）**。
- **外注先**（外注先メニュー）: 会社名、担当者、電話、メール、締め日、対応工程。
- 取引をやめた相手は削除せず、「有効」を外します。

## 3. 見積 → 受注 → 納品 → 請求（基本の流れ）

案件の画面（見積または案件メニュー → 「開く・変換」）の上部に、4つの段階が並びます。
**① 見積書 → ② 受注 → ③ 納品書 → ④ 請求書**

### 3.1 案件・見積の登録
1. 「見積」または「案件」で「新規見積」「新規案件」。
2. 得意先、案件名、担当、見積日、納期、客先注文番号、備考（帳票に印字）、社内メモ（帳票に出ません）を入力。
3. **品目**: 「行を追加」し、品名・数量・販売単価・原価単価・納期・税区分・外注先・仕様を入力。**製番は空欄で自動採番**（例: CRO261001-1）。製番はシステム全体の共通キーなので、後から変えません。
4. 「保存」。粗利（売上−原価）はシステムが計算して表示します。
- **AIで取込**: 見積依頼メールの本文、または注文書PDFから、案件の下書きを作ります。**結果は必ず目で確認・修正してから保存**します（自動では保存されません）。内容が難しいときは「高精度モデルを使う」を選びます。

### 3.2 ① 見積書の発行
- 右側の「発行イメージ」で内容を確認します。直す箇所は、「宛先」「記載項目」の欄と、左の入力です。
- **「見積書を発行・表示」**で、内容が固定されます（帳票の版が残ります）。同じ内容で押し直しても新しい版は増えず、内容を変えてから押すと新しい版になります。
- 帳票の画面で、印刷／PDF保存、送付、交付の記録をします（§5）。

### 3.3 ② 受注
- 「受注にする」で、状態が「受注」に、受注日が入ります。品目がないと押せません。
- 見積中のまま「納品書にする」を押すと、自動で受注になります。

### 3.4 ③ 納品（納品書）
- **全数納品**: 「納品書にする（残りを全数納品）」。残りの数量すべてを、納品日（上の欄）で納品として記録し、納品書を発行します。
- **分納**: 案件の画面下の「分納」で、納品日と**品目ごとの今回の納品数**を入れて「納品を記録」。受注数を超える納品はできません。
- 納品の時点の税率が行に固定されます（あとで税率が変わっても、その納品は変わりません）。
- 間違えたとき: 納品の行の「取消」（理由が必須）。**請求書に計上済みの納品は取消せず、先に請求書を取消します。**

### 3.5 ④ 請求（請求書）
請求書の作り方は3通りです。

| 方法 | 使う場面 | 操作 |
|---|---|---|
| 案件ごと | 1案件の未請求の納品をまとめて請求 | 案件の画面「請求書にする（未請求の納品をまとめて）」 |
| 納品ごと | 納品書1枚ずつ請求 | 納品メニュー → 「この納品を請求」 |
| 締め請求 | 月末などに、1社の複数案件を締め日でまとめて請求 | 請求メニュー → 「締め請求を作成」 → 得意先と締め日を選んで「作成」 |

- 作成した請求書は**下書き**です。請求書の画面で内容（請求日、対象期間、支払期日、税率別の内訳、合計）を確認し、**「発行済みにする」**。請求書番号と支払期日（得意先の締め・支払の設定から計算）は、作成した時点で決まります。「発行済みにする」で、下書きから発行済みになります。
- 発行済みの請求書は、「請求書（控え）を発行・表示」（正式化した場合は名称が変わります）で**帳票として固定**します。以降の送付・保存は§5。
- **二重請求の防止**: 請求済みの納品は、別の請求書に入りません。
- 間違えたとき: 請求書の画面の「取消」（理由が必須）。**入金が消し込まれている請求書は取消せず、先にその入金を取消します。** 請求書を取消すと、計上されていた納品は未請求に戻り、固定済みの帳票も取消になります。

## 4. 入金

1. 入金メニューの「入金を登録」。得意先、入金日、入金額、方法、**入金銀行**、**口座番号**（銀行振込のときは銀行と口座番号が必須）、先方が差し引いた振込手数料、メモを入力して「登録」。
2. **消込は自動**です。古い請求書（支払期日の早いもの）から順に充当されます。手数料は消込に含めます。足りない分・余った分は「未消込の入金（前受）」「得意先ごとの残高」に出ます。
3. 間違えたとき: 入金履歴の行の「取消」（理由が必須）。消込も戻ります。入れ直します。

## 5. 帳票の送付・保存（案A）

帳票の画面（帳票メニュー → 検索 → 「開く」、または案件・請求書の画面から）に、**送付の手順**があります。

1. **PDFをダウンロード**: 固定した内容から、日本語フォントを埋め込んだPDFを作ります。同じ内容なら、いつ作っても同じPDFです。ファイル名は「取引年月日_取引金額_取引先_帳票番号_v版.pdf」。
2. **お客様宛のメール**: メールの画面が開き、宛先・件名・本文が入ります。**PDFを添付して**送信します（ブラウザの仕様で、自動では添付できません）。
3. **Box宛のメール**: **別のメール**で、**同じPDF**を添付し、宛先は Box のアドレスだけにします（宛先が複数だと Box に保存されません）。
4. **交付を記録**（画面下の欄）: 方法（紙／PDF（メール）／Box保存／その他）、交付日、宛先を入力して「交付を記録」。「PDF（メール）」で記録すると、このシステムが作ったPDFが「送付したPDF」として保存されます（別のPDFを送ったときだけ、そのファイルを選びます。5MBまで）。Box にも送ったときは「Box にも保存した」にチェックします。
- **郵送・手渡し**は、「印刷／PDFとして保存」で印刷し、方法「紙」で交付を記録します。
- **宛先・記載項目の変更**: 帳票の右側の「宛先」「記載項目」の「変更」で、住所・担当部署・担当者・有効期限・納入場所・支払条件・振込先・担当者名・FAX・ロゴ・社印の**値と表示／非表示**を、この帳票だけ（または案件すべて／マスタにも）変更できます。**変更後は、帳票を発行し直す（新しい版）**必要があります。発行済みの版は変わりません。
- 出力した書面に手書きで加筆して渡したときは、その書面を**紙で保存**します（電子データだけでは足りません）。

## 6. 受領書類（受け取った書類）の登録

画面「受領書類」→「受領書類を登録」。メール等で電子データで受け取った書類（電子取引）と、紙で受け取った書類を読み取ったもの（スキャナ保存）を登録します。

- **電子データで受け取った**: ファイルを**そのまま**選びます（内容を打ち直したものは保存になりません）。書類の種類、授受日、**取引年月日・取引先・取引金額（税込）**を入力します。
- **紙を読み取って保存する**: 読み取ったファイル、読み取った日、**解像度（200dpi以上）**、**色**（重要書類＝契約書・納品書・請求書・領収書などは**カラー**、一般書類＝見積書・注文書・検収書などはグレースケール可）、ページ数、用紙サイズを入力します。
- **入力期限**（重要書類）: 受け取って**おおむね7営業日以内**に登録します。期限を過ぎた重要書類は、**紙の原本を保存**します（一覧に「期限超過: 紙の原本を保存」と出ます）。
- **紐づけ**: 重要書類は帳簿との関連づけが必要です。一覧の「紐づけ」で、関連する帳簿の伝票番号を後から追記できます。
- **タイムスタンプ**: 一覧の「タイムスタンプ」欄に、付与済み／付与待ち／期限超過が出ます。付与待ちは「付与を実行」。外部サービス（Box など）に任せる設定のときは「外部」と表示されます。
- 間違えたとき: 「取消」（理由が必須）。更新・削除はできません。
- **会社の運用（2026-11-01 決定）では、受領書類は Box に統一し、この画面は使いません**（`docs/事務手続書.md` §6）。Box の運用（アップロード期限、取引日・取引先・金額の入力、帳簿との紐づけ）は、事務手続書に従います。

## 7. 税務調査（ダウンロードの求め）への出力

画面「出力」。期間（取引年月日）や取消済みを含めるかを指定して、次を出します。
- **一覧CSV**: 発行済み帳票／受領書類／送付PDF（検索項目、ハッシュ、タイムスタンプの状況。Excelで開けます）。
- **一式のZIP**: CSV＋ファイル本体（受領書類・送付PDF・発行済み帳票の固定内容）。
- 出力時に、**ファイルのSHA-256が、登録時に記録した値と一致するか**を自動で照合し、結果を表示します。

## 8. 取消と訂正の早見表

| やりたいこと | 操作 | 注意 |
|---|---|---|
| 納品を間違えた | 納品の行の「取消」＋入れ直し | 請求済みなら先に請求書を取消す |
| 請求書を間違えた | 請求書の「取消」＋作り直し | 入金消込済みなら先に入金を取消す |
| 入金を間違えた | 入金履歴の「取消」＋入れ直し | |
| 発行済みの帳票の内容を直す | 元データ・宛先・記載項目を直して**再発行（新しい版）** | 旧版は残る。交付済みの旧版も保存される |
| 受領書類を間違えた | 「取消」＋登録し直し | 更新・削除はできない |
| 削除したい | **できません** | 取消で記録に残す |

## 9. 画面に出る主なメッセージ

| メッセージ | 意味と対処 |
|---|---|
| 取消理由を入力してください | 取消には理由が必須。入力して再度実行 |
| この納品は請求書に計上済みです。先に請求書を取消してください | 請求書を取消してから納品を取消す |
| 入金消込済みの請求書は取消できません。先に入金を取消してください | 入金を取消してから請求書を取消す |
| 納品数の合計が受注数量を超えます | 納品数を見直す（受注数量を変えるときは案件の品目を直す） |
| 請求対象の納品がありません | 締め日までの未請求の納品がない。締め日・得意先を確認 |
| 銀行振込の入金には、入金銀行と口座番号が必要です | 入金銀行と口座番号を入力 |
| 発行済みの請求書だけ帳票を発行できます | 請求書を「発行済みにする」してから帳票を発行 |
| 取消された納品の納品書は発行できません | 取消済みの納品は帳票にできない |

## 10. 見読可能装置・環境（自社で備える）

電子計算機（PC）、14インチ以上のカラーディスプレイ、カラープリンタと、この操作マニュアルを、保存場所で使える状態にしておきます（Box のガイドでも自社で備えるものとされています）。画面は最新の Chrome／Edge／Safari を想定しています。

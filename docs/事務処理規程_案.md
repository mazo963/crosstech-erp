作成: 2026-11-01（**案。確定前に、国税庁のサンプルとの照合と、顧問税理士の確認が必要**）
関連: `docs/事務手続書.md`（全体の手続）、`docs/操作マニュアル.md`、`docs/電帳法対応方針.md`、`docs/システム関係書類一覧.md`

- 国税庁が示すサンプル（「スキャナによる電子化保存規程」「国税関係書類に係る電子計算機処理に関する事務の手続を明らかにした書類」。一覧: https://www.nta.go.jp/law/joho-zeikaishaku/sonota/jirei/0021006-031.htm）は、**このセッションからは取得できず、読んでいません**。この案は、Box の公式ガイド（更新日 2026-08-18）と、`docs/電帳法対応方針.md`（国税庁の一次資料で確認済みの要件）を基に書いた**骨子**です。
- **確定の前に、国税庁のサンプルの項目と照合し、漏れ・表現の違いを直してください。税理士の確認も受けてください。**
- 【要決定】は会社として決める項目、【要確認】は法令・運用の確認が必要な項目です。**【決定】**は、2026-11-01 に会社として決めた項目です。
- 【決定】の内容: 受領した電子データは **Box に統一**。紙で受け取った書類は **Box でスキャナ保存**。入力期間は**業務処理サイクル方式の最長**（受領から最長2か月＋おおむね7営業日）。

# 第1部 スキャナによる電子化保存規程

## 第1条（目的）
この規程は、株式会社クロステック（以下「会社」）が、紙で受け取った国税関係書類を、スキャナで読み取って電磁的記録として保存する（以下「スキャナ保存」）ときの、手続と責任を定める。

## 第2条（対象書類）
1. 対象は、取引先から紙で受け取った、契約書・納品書・請求書・領収書・注文書・検収書・見積書など、国税関係書類（取引関係書類）とする。
2. 書類は、次の2つに区分する。【要確認: 区分の具体例は、税理士に確認する】

| 区分 | 例（資金や物の流れに直結・連動するか） |
|---|---|
| 重要書類 | 契約書、納品書、請求書、領収書 など |
| 一般書類 | 見積書、注文書、検収書 など |

3. 自社が作成して交付する書類の控え（見積書・納品書・請求書）は、販売管理システムで発行時の内容を固定して保存する（事務手続書 §5）。この規程の対象外とする。

## 第3条（責任者と担当者）
| 役割 | 担当者 | 職務 |
|---|---|---|
| 責任者 | 【要決定】 | この規程の運用の監督、規程の改廃、原本廃棄の承認、点検の確認 |
| 受領担当 | 【要決定】 | 書類の受領、スキャナでの読み取り、確認、Box へのアップロード |
| 確認担当 | 【要決定】（受領担当とは別の人が望ましい） | 読み取った画像の確認、入力項目の確認、点検 |

## 第4条（使用する機器とシステム）
1. 読み取りには、複合機またはスキャナ（200dpi以上で読み取れるもの）を使う。スマートフォンで撮影する場合は、書類がA4以内のときは約387万画素（縦2,338×横1,654）以上で撮影する。A4より大きい書類は、必要な画素数を税理士等に確認してから行う。【要確認】
2. スマートフォンの標準カメラで撮影した画像を、メール添付・チャット・ファイル共有で別の端末へ送る使い方は、解像度の要件を満たさない場合があるため、行わない。
3. 保存には、MF クラウドBox（以下「Box」）を使う。Box は、アップロード時にタイムスタンプを付与し、削除できない仕様である（Box の公式ガイド）。
4. 画像を確認できる、14インチ以上のカラーディスプレイとカラープリンタ、および操作マニュアルを備える（事務手続書 §8）。

## 第5条（入力期間）【決定】
1. 重要書類の入力期間は、**業務処理サイクル方式**とし、書類の受領後、**最長2か月＋おおむね7営業日以内**に Box へアップロードする（第2部の定める業務処理サイクルに従う）。
2. 一般書類は、受領後、同じ期間内にアップロードする。【要確認: 一般書類の入力期間の制限の扱い】
3. 期間内にアップロードできなかった重要書類は、**電磁的記録による保存に代えられないため、紙の原本を保存する**。責任者に報告する。

## 第6条（読み取りの手順）
受領担当は、書類を受け取ったら、次の順で行う。
1. 書類に、受領日を記録する（付箋・受領印・台帳など。【要決定: 方法】）。
2. 重要書類は**カラー**（赤・緑・青が各256階調以上、24ビット）、一般書類はカラーまたはグレースケールで、**200dpi以上**で読み取る。
3. 読み取った画像で、次を確認する。
   - 書類の全体が写っている（欠け・ぼやけ・折れ・裏面の記載漏れがない）
   - 読み取り条件（解像度・色）を満たしている
   - 複数枚の書類は、すべてのページがある
4. 画像に、加工（切り取り・補正・修正）をしない。やむを得ず加工したときは、加工前の画像も保存する。【要確認】
5. Box へアップロードする（第7条）。

## 第7条（Box での入力・タイムスタンプ）
1. アップロードの際に、次の項目を入力する。入力した内容は、確認担当が原本と照合する。
   - **取引年月日**（書類に記載の日付）
   - **取引先名**（書類に記載の名称）
   - **取引金額**（書類に記載の合計額。税込）
2. Box のアップロード機能で、タイムスタンプが付与されることを確認する（ファイルの詳細画面で「付与済み」）。
3. 検索は、Box のファイル画面で、取引年月日・取引先・取引金額で行う。

## 第8条（帳簿との相互関連性）【重要書類のみ】
1. 重要書類は、帳簿との相互関連性を保つ。
2. 当社は会計ソフトを持たず、会計処理は顧問税理士が行うため、次のいずれかの方法とする。【要確認: 税理士と決める】
   - 税理士が、MF 会計の「証憑添付」で、Box の書類を仕訳に添付する
   - 仕訳の摘要欄などに、Box の「ファイルID」を残す
3. 保存の時点で帳簿が未作成のときは、決算が終わった後、遅滞なく関連づける。
4. 税理士へ渡す売上・入金のデータには、書類番号や Box のファイル名を付ける。【要決定】

## 第9条（原本の扱い）
1. 紙の原本は、スキャナ保存の要件を満たしたことを確認した後、**責任者の承認を得て**廃棄できる。【要確認: 廃棄の時期・条件は、国税庁の資料と税理士で確認する】
2. 第5条第3項のとおり、入力期間を過ぎた重要書類は、廃棄しない。
3. 原本に手書きの書き込みがある書類は、読み取りに加えて、原本も保存する。【要確認】

## 第10条（訂正・削除の防止）
1. Box に保存したファイルは、削除しない。Box は、スキャナ保存の区分に該当する可能性のあるファイルを削除できない仕様である。
2. 間違えて保存したときは、削除せず、責任者に報告し、正しい画像を新たに保存する。間違いの内容と理由は記録する。【要決定: 記録の方法】
3. 取引年月日・取引先・金額の入力の誤りは、Box の機能で訂正する場合に、訂正の履歴が残ることを確認する。【要確認】

## 第11条（保存期間・保存場所）
1. 保存期間は、**7年**とする。欠損金額が生じた事業年度（青色繰越欠損金等）の書類は、**10年**とする。起算日は、確定申告書の提出期限の翌日とする。
2. 保存場所は Box とする。保存期間中は、削除しない。
3. 保存期間を過ぎた書類の廃棄は、責任者の承認を得て行う。【要決定】

## 第12条（見読・検索・ダウンロードの求め）
1. 税務調査等で求められたときは、Box の画面と、カラープリンタで、速やかに出力できるようにする。
2. 検索は、取引年月日・取引先・取引金額で行える。範囲指定と2項目以上の組合せが必要な場合は、Box のファイル画面で行う。【要確認: 基準期間の売上高が5,000万円以下の場合は、ダウンロードの求めに応じられることで足りる。税理士に確認】

## 第13条（システム関係書類）
Box は他社が提供するサービスのため、当社の備付けは不要とされている（Box の公式ガイド）。一方、自社で開発した販売管理システムの関係書類は、`docs/` に備え付ける（`docs/システム関係書類一覧.md`）。

## 第14条（点検）
責任者または確認担当は、**月に1回**、次を確認する。【要決定: 記録の方法】
1. 受領した書類が、期間内に Box に保存されているか（未処理の書類の有無）
2. タイムスタンプが付与されているか
3. 取引年月日・取引先・取引金額の入力が、原本と一致しているか（抜取りでよい。【案】）
4. 重要書類の、帳簿との関連づけが済んでいるか
5. 入力期間を過ぎた書類が、紙の原本で保存されているか

## 第15条（教育）
責任者は、受領担当・確認担当に、この規程と Box の操作を、担当になる前に説明する。【要決定: 実施の時期】

## 第16条（規程の改廃）
この規程の改廃は、責任者が案を作り、会社の代表者が承認する。改廃したときは、全員に周知し、改廃の履歴を残す。

# 第2部 各事務の処理に関する規程（業務処理サイクル）

## 第17条（業務処理サイクルの定義）【要決定】
1. 会社は、取引の受領から保存までを、**【案】受領した月の翌月の末日までを1つの業務処理サイクル**として処理する。ただし、**受領から2か月を超えない**ものとする。【最長を選ぶ、という会社の決定に基づく案。具体的な定義は、税理士と決める】
2. 各担当は、サイクルの途中でも、受領後、できるだけ早く処理する。

## 第18条（処理の手順と期間）
| 事務 | 担当 | 期間 | 内容 |
|---|---|---|---|
| 受領 | 受領担当 | 受領当日 | 書類を受け取り、受領日を記録する（第6条1） |
| 読み取り・確認 | 受領担当・確認担当 | サイクルの範囲内で速やかに | 第6条 |
| アップロード・入力・タイムスタンプ | 受領担当 | **サイクルの終了後、おおむね7営業日以内**（受領から最長2か月＋おおむね7営業日） | 第7条 |
| 帳簿との関連づけ | 税理士（または受領担当） | 決算終了後遅滞なく | 第8条 |
| 点検 | 責任者・確認担当 | 月に1回 | 第14条 |

## 第19条（期間を超えたとき）
期間を超えた重要書類は、紙の原本を保存し、責任者に報告して、原因と再発防止を記録する（第5条3項）。

## 第20条（施行）
この規程は、【要決定: 年月日】から施行する。

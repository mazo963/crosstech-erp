# 税理士への確認メモ（クラウドBox と 弥生会計の運用について）

宛先：顧問税理士　／　差出人：株式会社クロステック　／　作成日：2026-11-01

お世話になっております。当社では、販売管理システムを自社で整備しており、見積書・納品書・請求書をシステムで発行して PDF でお送りし、**送ったPDFと受け取った書類を MF クラウドBox に保存**する運用を考えています。会計処理は、これまでどおり先生（弥生会計をお使いと伺っています）に、当社から渡すデータを取り込んでいただく形を想定しています。

電子帳簿保存法への対応にあたり、次の点を教えてください。

## 1. 書類と仕訳の紐づけ（証憑添付）

MF クラウドBox のガイド（更新日 2026-08-18）では、**重要書類**（納品書・請求書・領収書など）は帳簿との相互関連性が必要で、次のいずれかの対応が示されています。

- MF クラウド会計の「証憑添付」で、Box の書類を仕訳に添付する
- 他の会計ソフト（弥生会計など）では、Box の「ファイルID」を仕訳の摘要欄などに入力する

質問：
1. 先生の事務所は弥生会計とのことですが、MF 会計も併用されていますか（MF クラウドのユーザーには登録済みと伺っています）。MF 会計で「証憑添付」を使っていただくことは可能ですか。
2. 弥生会計の仕訳の摘要欄に、Box の「ファイルID」を残していただくことは可能ですか（摘要欄の文字数に収まりますか。収まらない場合の代わりの方法はありますか）。
3. 当社側で、仕訳の元になる一覧に、書類番号や Box のファイル名を付けて渡したほうがよいですか。

## 2. 渡すデータの形式

当社のシステムには、売上（請求）・入金などの情報があります。税理士の方へ渡すための **売上（請求書を税率ごとに1行）と入金の一覧を、CSV で出す機能は作成済み** です（特定の会計ソフトの形式ではありません）。形式を先生の希望に合わせたいので、教えてください。

質問：
4. 弥生会計に取り込める形式（仕訳日記帳のインポート形式など）で出力します。**取り込みに使う形式の見本（弥生からエクスポートした仕訳のファイル、または取込用のひな形）を、1つ送っていただけますか。** あわせて、次を教えてください。
   - 売上の仕訳の、勘定科目・補助科目・税区分の使い方（例: 借方「売掛金」／貸方「売上高」。補助科目に得意先名を入れるか）
   - 入金の仕訳の、勘定科目（例: 借方「普通預金」＝入金銀行ごとの科目名、貸方「売掛金」）と、振込手数料の扱い（借方「支払手数料」など）
   - 税率別（10%・軽減8%）の税区分の表記（弥生の税区分名）
   - 1行の単位（請求書単位か、明細単位か）、伝票番号・摘要に入れてほしい情報
5. データを渡す頻度（毎月、締め後など）と期限の希望はありますか。
6. 消費税は、請求書1枚・税率ごとに1回端数処理した金額で出します。仕訳の消費税の扱いで、気をつけたい点はありますか。

## 3. 保存と運用の規程

Box のガイドでは、受領からおおむね7営業日以内のアップロードが必要で、規程を定めれば最長2か月＋おおむね7営業日に延ばせるとされています。また、自社で開発したシステムを使う場合は、システムの概要を記載した書類の備付けが必要とされています。

質問：
7. 当社の規模で、「電子取引データの訂正削除の防止に関する事務処理規程」や「スキャナによる電子化保存規程」を作成しておくべきでしょうか。ひな形（国税庁のサンプル）を基に当社で作成し、内容を見ていただくことは可能ですか。
8. 紙で受け取った重要書類（納品書・請求書など）を、スキャンして Box に保存し、原本を廃棄する運用にしてよいか、先生のお考えを教えてください（保存する場合は、カラーで 200dpi 以上、受領後おおむね7営業日以内などの要件があります）。
9. 当社の「基準期間の売上高」は検索要件の緩和（5,000万円以下）の対象になりますか。

## 4. 参考（当社側の状況）

- Box の契約はビジネスプラン（保存件数の制限なし）です。先生は MF クラウド（Box を含む）に管理者として登録済みで、Box の書類を閲覧できます。
- 消費税は、請求書1枚・税率ごとに1回、端数処理しています（インボイスの要件）。
- 飲食料品の税率引下げ（令和9年4月1日〜令和11年3月31日の予定）に備え、複数税率に対応しています（法案成立の確認後に登録）。

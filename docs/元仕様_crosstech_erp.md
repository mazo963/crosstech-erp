# CROSSTECH 統合販売管理システム 運用マニュアル & 仕様書

本ドキュメントは、株式会社クロステック向けに構築された「統合販売管理システム（ERP）」の機能仕様、初期設定、実務運用手順をまとめたものです。

---

## 1. システム初期アクセス情報

初回のログインには以下の管理者アカウントを使用してください。

| 項目 | 設定値 | 備考 |
| :--- | :--- | :--- |
| **Staff ID** | `admin` | システム初期管理ID |
| **Access Key** | （削除） | 初期パスワード |

> ※ ログイン後、「マスタ管理」タブより実務担当者（スタッフ）の個別アカウントを登録できます。

---

## 2. マスタ管理（初期セットアップ手順）

実務で案件を登録する前に、まずマスタ情報の登録を行います。

### 2.1 スタッフ登録
- **機能概要**: システムを利用する社内スタッフのアカウントを作成します。
- **設定項目**:
  - 氏名
  - ログインID
  - パスキー（パスワード）
- **運用**: 案件作成時の「担当Lead」の選択肢として連動します。

### 2.2 得意先登録
- **機能概要**: 発注元（顧客）の取引条件や帳票送付先を設定します。
- **設定項目**:
  - **基本情報**: 得意先名称、先方担当者名、所在地
  - **インボイス**: 適格請求書発行事業者登録番号（T+13桁）
  - **回収条件**: 締め日（5日/10日/15日/20日/25日/末日/都度）、支払日（当日/翌月5日/翌月10日/翌月末/翌々月末など）
  - **計上基準**:
    - `都度納品`: 分納ごとにその都度請求を立てる運用
    - `全数完納`: すべての納品が完了した時点で一括請求する運用
  - **メール配信設定**:
    - **請求書用**: TO（主宛先）、CC（同報先）
    - **納品書用**: TO（現場・検収担当宛先）、CC（同報先）

### 2.3 外注先登録
- **機能概要**: 表面処理や追加工などの外部委託先を管理します。
- **設定項目**:
  - 外注先名称
  - 担当者名
  - 締め日

---

## 3. 案件・売上管理（メイン業務フロー）

1つの案件に対して複数品目（製番）を紐付け、仕入原価と売価から粗利を自動計算します。

### 3.1 案件登録（見積・受注）
1. 「案件・売上管理」画面の右上 **「新規登録」** をクリック。
2. 得意先および社内担当者を選択。
3. 案件名称、備考（検収条件・特記事項など）を入力。
4. **品目リストの入力**:
   - 品名・仕様
   - 製番（社内Job No.）
   - 仕入先（自社加工 または 外注先マスタから選択）※社内管理用
   - 数量
   - 買単価（原価）
   - 売単価（見積・売価）
   - 「＋」ボタンで複数品目を同一案件内に追加可能。
5. 保存を実行すると、即座に売上額・粗利額・進捗がダッシュボードおよび一覧へ反映されます。

---

## 4. 分納対応と帳票発行フロー

### 4.1 納品管理（分納機能）
1. 案件一覧の右側にある **トラックアイコン（納品記録）** をクリック。
2. 今回納品を行う品目について、数量（今回数）を入力。
3. **「納品を記録して納品書を発行」** をクリック。
4. **自動処理**:
   - 入力した数量のみを記載した「納品書」プレビュー画面へ遷移。
   - 案件全体の納品進捗（バー表示）が更新。
   - 全数納品に達した場合はステータスが自動的に「納品完了」に切り替わり、一部の場合は「分納中」となります。

### 4.2 見積書・請求書の発行
- **見積書**: 案件一覧の **書類アイコン（御見積書）** から出力。
- **請求書**: 案件一覧の **履歴/ダウンロードアイコン（請求書）** から出力。
- すべての帳票には以下が自動反映されます：
  - 自社情報（会社名、インボイス登録番号、TEL、所在地）
  - 案件固有の備考欄テキスト
  - 消費税（10%）および税込合計額

## 5. メールソフト連携（PDF送信準備）

ブラウザのセキュリティ制約によりPDFの自動添付は行えませんが、宛先や本文の自動入力により送信作業を省力化します。

1. 各種帳票（見積書・納品書・請求書）のプレビュー画面を表示。
2. 右下の **「メール作成」** ボタンをクリック。
3. **「Email Console」モーダルの起動**:
   - 得意先マスタに設定した宛先が自動で判別されます。
     - 納品書プレビュー時 ➡ 得意先の「納品書用TO/CC」
     - 請求書プレビュー時 ➡ 得意先の「請求書用TO/CC」
   - 件名・本文に案件名、税込金額、宛先名が自動挿入。
4. **「メールソフトを起動」** をクリックすると、端末の標準メーラー（Outlook、Gmail等）が宛先・件名・本文を入力済みの状態で起動。
5. 事前に「印刷 / PDF保存」で出力したPDFファイルをドラッグ＆ドロップして送信を完了します。

---

## 6. ダッシュボード・経営指標

ログイン直後のダッシュボードでは、以下の数値がリアルタイムで集計されます：

- **総受注額**: 登録された全案件の売価合計
- **総粗利益**: （売上額 - 仕入・加工原価）の合計額
- **平均粗利率**: 全案件の利益率平均（%）
- **未回収残高**: 状況に応じた未回収売掛金モニタリング

## 7. トラブルシューティング

| 症状 | 原因 | 対処法 |
| :--- | :--- | :--- |
| **画面が真っ白になる** | コードの末尾欠落やJavaScriptの構文エラー | 提供された最新の単一ファイルコード全体を再度適用してください。 |
| **ログインできない** | 入力ID・パスワードの誤り | 初期ID: `admin` / パスワード: （削除） を半角英数で入力してください。 |
| **マスタ追加画面が開かない** | モーダル表示用のState不整合 | ページを再読み込みし、ログイン状態を確認した上で再度お試しください。 |
| **メールソフトの宛先が空欄になる** | 得意先マスタにアドレスが未設定 | 「マスタ管理」→「得意先」の編集（歯車アイコン）から請求書用/納品書用メールアドレスを設定してください。 |
